# ニチヨウマート（架空の会社）

このフォルダは RAG Security Lab のサンプル会社「ニチヨウマート」のデータです。
会社も顧客も注文も、すべて架空です。実在の企業・人物とは関係ありません。

## 会社概要

| 項目 | 内容 |
| --- | --- |
| 会社名 | ニチヨウマート |
| 業態 | 自社商品だけを売る中規模の通販会社（衣類と家電） |
| ドメイン | nichiyo-mart.example |
| マイページ | https://nichiyo-mart.example/mypage |
| サポート窓口 | support@nichiyo-mart.example（平日10〜18時、メールのみ） |

## 会社のルール

FAQ・利用規約・問い合わせは、すべてこのルールに合わせて作る。日数や金額を変えるときは、ここを直してから各データを直す。

### 注文・配送

| 項目 | ルール |
| --- | --- |
| 出荷 | 注文から3〜5営業日以内に出荷。出荷後、到着まで1〜2日が目安 |
| 送料 | 1注文5,000円（税込）以上は無料。未満は全国一律550円（税込） |
| 追跡 | 出荷時に追跡番号をメールで通知。マイページの注文履歴からも確認できる |
| 配送先の変更 | 出荷前ならマイページから変更可。出荷後は配送業者へ直接連絡 |
| キャンセル | 出荷前ならマイページから可。出荷後は不可（到着後に返品で対応） |
| 日時指定 | 配達日と時間帯（午前中、14〜16時、16〜18時、18〜20時）を指定可。離島は時間帯指定不可 |

### 返品・返金

| 項目 | ルール |
| --- | --- |
| 返品 | 到着後14日以内、未使用・タグ付きのみ。客都合の返品は送料客負担 |
| 返品の手順 | マイページの注文履歴から申請 → 返送用ラベルをメールで送る → 14日以内に発送 |
| 初期不良・破損 | 到着後30日以内。無償交換か全額返金を客が選ぶ。送料は会社負担 |
| 誤配送 | 開封済みでも受付。正しい商品を会社負担で再送。返送も無料 |
| 返金 | 返品確認後7営業日以内。クレカは元のカードへ、コンビニ払い・代引きは銀行振込 |
| セール品 | 通常の条件で返品可。ただし「返品不可」と明記の商品は不可 |

### クーポン

| 項目 | ルール |
| --- | --- |
| 使い方 | 注文手続きの「クーポンコード」欄に入力して適用 |
| 枚数 | 1注文1枚。併用不可 |
| 対象外 | セール品には使えない。セール品と通常品の同時注文は、通常品の分だけ割引 |
| 事後適用 | 注文確定後の適用・割引分の返金は不可 |
| 配布 | メルマガ登録で初回10%OFF。誕生月、LINE友だち追加でも配布 |

### 衣類

| 項目 | ルール |
| --- | --- |
| サイズ交換 | 到着後14日以内、未使用・タグ付き。1回まで無料 |
| 色違いへの交換 | サイズ交換と同じ条件。希望の色に在庫がある場合のみ |
| サイズ案内 | 商品ページにサイズ表と実寸、モデルの身長と着用サイズを掲載 |
| 洗濯 | 商品の洗濯表示に従う。ニット・ウールは手洗いかドライクリーニング推奨 |
| 再入荷 | 商品ページの「再入荷通知」でメール通知。予定がない商品は「販売終了」表示 |

### 家電

| 項目 | ルール |
| --- | --- |
| 保証 | メーカー保証1年。保証書は納品書と同梱。延長保証の取り扱いはない |
| 修理 | サポート窓口に注文番号と症状を連絡。保証期間内は無償（取扱説明書どおりの使用に限る）。期間外は見積もり後に有償 |
| 修理の期間 | 預かりから返却まで2〜3週間が目安。部品取り寄せでさらにかかることがある |
| 取扱説明書 | 商品ページからPDFでダウンロード可。販売終了品のページも残す |
| 設置サービス | 大型家電（冷蔵庫、洗濯機、乾燥機）は注文時に申込可。3,300円（税込）。古い家電のリサイクル回収も同時に申込可 |
